# 🧠 AI & Research Projects

### 🐛 Smartraps: AI & IoT Device for Insect Pest Surveillance
**2023 – 2024 · MNS University of Agriculture**

| | |
|---|---|
| **Problem** | Farmers rely on manual trap inspection and blanket pesticide spraying, which is slow, costly and harmful to the environment. |
| **Solution** | A solar-powered field trap with an onboard camera that runs deep-learning detection (YOLO / Faster R-CNN) and streams pest counts, temperature and humidity to a mobile app. |
| **Impact** | Pinpoints pest hotspots in real time, enabling targeted control that cuts pesticide use. Featured by NUST Research and published in *Nature Scientific Reports*. |

`YOLOv8x` `Faster R-CNN` `PyTorch` `ESP32 / IoT` `Solar Power` `Android` `Sensors`
